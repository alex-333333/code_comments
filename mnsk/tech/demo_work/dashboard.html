Плотность комментариев

Сколько комментариев приходится на 100 строк кода, добавленных коммитами. Считается одинаково для обоих корпусов; в знаменателе все добавленные строки, включая файлы без единого комментария. Фильтр «Язык» действует; порог θ и метрика - нет.

Насколько комментарий пересказывает код

overlap - доля содержательных слов комментария, которые уже есть в соседнем коде. Чем правее, тем больше комментарий повторяет код. Столбики - доли комментариев в диапазонах шириной 0.05.

Стиль и форма

Докстринги (отдельно)

Описывают функцию целиком, поэтому в основную метрику не входят.

Как это считается

Определения

overlap = |стемы содержательных слов комментария ∩ стемы кода| / |стемы содержательных слов комментария|. Служебные слова не считаются; идентификаторы snake_case и camelCase разбираются на слова; сравнение по стемам (Snowball). Комментарии короче 3 содержательных слов и комментарии без привязанного кода в overlap не участвуют.

Referential: overlap ≥ θ и нет маркеров «почему». Explanatory: есть хотя бы один маркер причины, цели, противопоставления, предупреждения, условия, истории, ссылки или тег TODO/FIXME. Other: остальное.

Что учитывается. Только комментарии, целиком добавленные атрибутируемым коммитом; без лицензий, директив линтеров, закомментированного кода и не-английских текстов; без точных дублей внутри репозитория.

Доверительный интервал для разницы долей считается бутстрепом по репозиториям, а не по комментариям: комментарии одного проекта не независимы.
